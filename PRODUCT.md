## Platform

web

## Stack

Delegated to Codex after options were explained: Next.js App Router with TypeScript for the web application and server endpoints, Supabase for PostgreSQL, authentication, and media storage, and Vercel as the recommended deployment target.

## Users

- Prospective clients evaluating Afsun Filosof for creative, content, branding, design, or web work.
- Recruiters and HR teams evaluating professional experience, capabilities, outcomes, and role fit.

## Product Purpose

Present Afsun's multidisciplinary body of work across different media formats in one coherent professional portfolio. Success means visitors can understand his value quickly, inspect relevant work in depth, and contact him for a project or employment opportunity.

## Positioning

A multidisciplinary creative portfolio that connects brand thinking, visual execution, content performance, and technology-assisted web implementation instead of presenting each medium as an unrelated specialty.

## Operating Context

Visitors often arrive from a CV, job application, shared project link, or professional conversation. They may scan quickly on mobile or review case studies more deliberately on desktop. Afsun needs to manage projects and mixed media without editing source code.

## Capabilities and Constraints

- Multiple public pages: Home, Work archive, project detail, About, and Contact.
- A private admin surface manages projects, categories, media, ordering, and publication state.
- Project media may include images, image galleries, short videos, PDFs, and external web links.
- The Home page opens with a large PORTFOLIO statement, transitions into a sticky portrait and changing CV-derived narrative, then leads into selected work and professional proof.
- Desktop may use scroll pinning. Mobile must use a natural vertical sequence and preserve access to all content.
- Public facts and metrics must come from the supplied CV or later user-approved evidence.
- The project currently contains one approved transparent portrait asset at `afsun.webp`.
- Exact production Supabase credentials, final domain, original project assets, and downloadable CV file are open deployment/content decisions.

## Product Principles

1. Let real work and measurable outcomes lead.
2. Keep different disciplines connected by one clear professional narrative.
3. Make deep review rewarding without slowing down fast scanning.
4. Preserve factual integrity and clearly label draft or demonstration content.
5. Use motion to reveal hierarchy and progression, never to block access.

## Accessibility & Inclusion

Target WCAG 2.2 AA for contrast, keyboard navigation, focus visibility, semantics, and form feedback. Every meaningful image needs useful alternative text. Motion must respect `prefers-reduced-motion`, and pinned storytelling must have a readable non-pinned mobile form.
